# gpu_compat.h

прослойка между hip и cuda. движок пишется на именах hip (hipMalloc, hipblasLt и т.д.), а при сборке под nvidia этот файл переводит их в cuda и cublasLt. здесь же типы half и bfloat16, размер волны (TIER_WARP) и мелкие функции, которые на двух платформах называются по разному.
при сборке под amd файл почти пустой. правка нужна, когда движок начинает звать новую функцию hip, которой нет в списке.
