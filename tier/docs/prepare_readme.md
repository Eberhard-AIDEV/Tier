# prepare.py

готовит данные: читает примеры jsonl (вопрос, ответ, системная инструкция), размечает их шаблоном диалога модели (tmpl.py) и пишет токены в бинарный файл движка: <имя>_tokens.bin и отложенную часть <имя>_eval.bin. рядом пишет статистику длин (<имя>_stats.txt) и счёт системных инструкций (<имя>_scenes.json) для подмешивания.
окружение: MODEL, NAME, WORK, HOLD (сколько примеров отложить).
